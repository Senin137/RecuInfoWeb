# Conclusión AC-9: Línea de tiempo y tendencias por tema

El análisis temporal se realizó con granularidad **mes**. Se eligió granularidad mensual porque el rango temporal del corpus es de 4311 días; esto reduce ruido y permite comparar tendencias agregadas con mayor estabilidad.

El corpus analizado cubre **41 periodos** y las categorías principales fueron: ciencia, economia, tecnologia, deportes, gobierno.

La categoría con mayor presencia acumulada fue **ciencia**, con **309 noticias**.
